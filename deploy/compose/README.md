# Docker Compose recipes

One folder per recipe. Choosing, pinning, verifying and updating are in
[Install with Docker](../../docs/Install-Docker.md); the release files for
`caddy-files` and `httpd-files` are in
[Docker recipes without the PassGen image](../../docs/docker.md); HTTPS options
are in the [HTTPS guide](../../docs/docker-https.md).

| Folder | What runs |
|---|---|
| `caddy-https/` | PassGen image behind Caddy, which handles HTTPS (recommended) |
| `localhost/` | PassGen image on `127.0.0.1:8080` for a proxy already on the host |
| `caddy-files/` | Verified release files in the official Caddy image, with HTTPS |
| `httpd-files/` | Verified release files in the official httpd image on `127.0.0.1:8080` |

The `caddy/` and `httpd/` folders are generated by `pnpm headers:gen` from the
same source as `deploy/examples/`; do not edit them by hand.
